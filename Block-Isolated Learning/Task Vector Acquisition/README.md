# Task Vector Acquisition

## Environment

The requirements are provided in `requirements.xlsx`.

## Download the Pre-trained Language Model

Download the pre-trained model `BAAI/bge-small-en-v1.5` from the Hugging Face website, and place the model files in the folder `models/bge/bge-small-en-v1_5`.

## Get Task Vectors

Simply run `s_modification+SuperNI+bge+all.sh`. Then, run `average+bge+all.sh`.

## Task Vectors

You can find task vectors in `pooler_vectors/all_pooler_vectors/bge/bge-small-en-v1_5.tar`.
